## 📌 Project Overview
Professional business intelligence dashboard analyzing 10,000+ sales transactions with real-time insights and interactive visualizations. This project demonstrates end-to-end data analysis skills required for Data Analyst roles.

## ✨ Key Features
- 📊 **5 KPI Metrics**: Total Revenue, Orders, Customers, Average Order Value, Monthly Growth
- 📈 **6 Interactive Charts**: Monthly trends, regional analysis, product performance, category distribution
- 🎯 **Dynamic Filters**: Date range, region, category, customer segment
- 🐍 **Python Pipeline**: Automated data generation, cleaning, and analysis
- 🌐 **Web Dashboard**: Responsive HTML/CSS/JavaScript interface with Chart.js

## 🚀 How to Run Locally

### Prerequisites
```bash
pip install pandas numpy matplotlib seaborn faker
```

### Step 1: Generate Data
```bash
cd scripts
python 1_generate_data.py
```

### Step 2: Analyze Data
```bash
python 2_data_analysis.py
```

### Step 3: View Dashboard
Open `dashboard/index.html` in your web browser

## 📊 Dashboard Components

### KPI Cards (Top Section)
- 💰 **Total Revenue**: Year-to-date sales performance
- 📦 **Total Orders**: Number of transactions processed
- 👥 **Total Customers**: Unique customer count
- 💵 **Average Order Value**: Revenue per transaction
- 📈 **Monthly Growth**: Month-over-month growth percentage

### Trend Analysis (Middle Section)
- 📈 **Monthly Sales Trend**: Line chart showing sales over time
- 🌍 **Revenue by Region**: Bar chart comparing regional performance
- 🏆 **Top 10 Products**: Horizontal bar chart of best-selling products

### Business Insights (Bottom Section)
- 📊 **Sales by Category**: Pie chart showing category distribution
- 💎 **Top Customers**: Table listing highest-value customers
- 💰 **Profit by Region**: Bar chart showing regional profitability

### Interactive Filters
- 📅 Date Range Selector
- 🌍 Region Filter
- 📦 Product Category Filter
- 👔 Customer Segment Filter
